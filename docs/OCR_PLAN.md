# OCR 后续计划

OCR 是增强能力，不是当前稳定版生成 Word/PDF/Excel 材料的前置条件。

## 当前能力

- RapidOCR + ONNX Runtime 本地识别，不上传云端。
- GUI 检测到 JPG/JPEG/PNG 后自动执行 OCR。
- 使用目标月份进行方向评分，不固定 7 月或固定期次。
- 保存 OCR 原文和调试结果；低置信度记录要求人工核对。
- 失败时提示并允许手工补录，普通材料处理继续进行。

## v1.1.0 建议清单

1. 建立脱敏的多月份、多角度、多清晰度图片 benchmark。
2. 增加不同课程表版式和跨页照片样例。
3. 记录召回率、日期准确率、教师命中率和课时准确率。
4. 优化失败提示，但不改变 preview 优先和人工确认原则。
5. 每次 OCR 修改必须回归 Word、PDF、Excel 与最终写入流程。

## 不可突破的安全边界

- 不根据低置信度内容猜测日期、教师或课时。
- OCR 失败不闪退、不阻断普通材料。
- 真实照片不得提交公开仓库。
