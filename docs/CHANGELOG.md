# 变更记录

## v1.0.0 — 2026-06-30（稳定版候选，待 GitHub 发布）

- 完成新版 GUI EXE 轻量冒烟与 SHA256 固化。
- 建立 `release/latest`、`release/backup`、发布历史、用户手册、验收测试和开发交接文档。
- GUI 图片材料自动 OCR；CLI 仍通过参数控制 OCR。
- 保留 `v1.0` 历史标签和旧版 EXE，不覆盖已有发布记录。
- GitHub 标签、Release 和新版附件尚未创建，审核通过后执行。

## v1.1 — 未发布

- GUI上传图片后自动执行OCR。
- 移除“启用图片OCR”“检测OCR”及工具菜单OCR自检交互。
- OCR失败仍保留中文提示、解析日志和手工补录退路。

## v1.0 — 2026-06-29（正式验收版）

- 朋友端到端测试通过：EXE启动、说明理解、preview、Excel生成与打开、同名文件避让均通过。
- v1.0内测候选版正式升级为v1.0正式验收版。
- 同名Excel覆盖风险已修复，自动使用 `_1`、`_2` 等新文件名。
- 发布说明已与当前GUI同步。
- OCR月份固定加权和固定期次偏置已处理。
- 本版本正式冻结，不再新增功能；后续新需求进入v1.1。

## v1.0 — 2026-06-29（内测候选版历史记录）

- 任意月份、模板、输入和输出参数化。
- 中文 GUI 与 CLI 共用解析、分类和写入逻辑。
- 支持 Word、PDF、Excel、图片及可选 RapidOCR。
- 支持简称及多人教师命中，培训/考核分模块写入。
- 增加同月份 preview 快照、写入确认和未确认项阻断。
- onefile EXE 内置 OCR 依赖和模型。
- 移除旧的专用快速补录按钮，普通“手工补录课程”保留。
- 最终 Excel 同名时自动使用 `_1`、`_2`，不覆盖已有文件。
- OCR方向评分改为使用用户选择的目标月份，并移除固定期次加权。
- 二次定点修复后评分91/100，随后进入朋友端到端测试。

## 封版已知问题

- CLI 异常会显示技术堆栈，重定向中文可能乱码。
- 尚无独立自动化测试套件和脱敏固定样例。
- OCR 仍受照片质量影响。
