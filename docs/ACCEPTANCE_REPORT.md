## 已完成的结项修复

1. 同名最终Excel自动使用 `_1`、`_2` 等新文件名，不覆盖已有文件。
2. 发布说明与当前GUI一致，只描述实际可见的操作入口。
3. OCR方向评分使用目标月份，移除固定7月及固定期次偏置。
4. 内测候选版经朋友端到端测试通过，升格为正式验收版。

## 剩余非阻断风险

- OCR仍受照片模糊、反光、倾斜、遮挡和裁切影响，必须核对preview。
- 尚缺非7月份真实照片的完整benchmark。
- CLI中文乱码和技术堆栈影响开发者体验，但GUI/EXE正式入口不受影响。
- 旧 `.doc/.xls` 和严格保持格式依赖Windows及Microsoft Word/Excel。

## 下一版本建议

- 更完整的OCR月份通用化和更多月份benchmark。
- 更清晰的GUI错误提示。
- 干净机器自动化测试。
- 建立更多脱敏样例和可重复回归。
