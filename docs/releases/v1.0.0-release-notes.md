- 当前版本：v1.0.0 稳定基础版

## 当前功能

- 中文 Windows GUI，面向非程序员和培训管理人员。
- 导入工作量表模板及 Word、PDF、Excel、图片课表材料。
- 按目标年月和教师生成 preview，再生成最终 Excel。
- 区分培训与考核，支持理论、实训及教师简称识别。
- 同名最终 Excel 自动使用 `_1`、`_2` 等新文件名，不覆盖原文件。
