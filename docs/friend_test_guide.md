# v1.0 用户测试与复核指南

当前版本为v1.0正式验收版，已完成朋友端到端测试。本指南保留用于新电脑复核和后续回归。

## 测试前准备

- 使用 Windows 电脑。
- 安装 Microsoft Word 和 Microsoft Excel。仅有 WPS 时，旧 `.doc/.xls` 和格式保留可能失败。
- 先准备测试材料熟悉流程，不要直接处理唯一原件；重要文件必须自行备份。

## 操作步骤

1. 将收到的 ZIP 保存到本地，右键选择“全部解压”。不要直接在压缩包内运行。
2. 打开解压后的“用户发布包”文件夹，双击 `月度工作量表自动生成器.exe`。
3. 点击“上传工作量表模板”，选择 `.xls` 或 `.xlsx` 模板。
4. 点击“上传课表/通知材料”，选择 Word、PDF、Excel 或图片；也可以导入材料文件夹。
5. 设置目标年份、月份和教师。图片需要识别时，先点击“检测 OCR”，再勾选“启用图片 OCR”。
6. 点击“生成预览”，检查待写入课程、被排除课程、考核汇总和解析日志。
7. 确认年月、课程、教师、分类和课时正确后，点击“生成最终 Excel”。
8. 程序不得覆盖已经存在的同名 Excel；如同名文件存在，应生成 `_1`、`_2` 等新文件。记录界面显示的实际保存路径。
9. 点击“打开 Excel”，确认文件能够正常打开，表头月份正确，培训和考核位置正确。

当前界面可使用“手工补录课程”；没有针对特定工种的专用快速补录按钮。

- EXE 能不能打开？
- 操作说明看不看得懂？哪一步不清楚？
- preview 有没有成功生成？
- 最终 Excel 有没有成功生成？
- 生成的 Excel 能否正常打开？
- 同名文件存在时，有没有生成新文件而不是覆盖？
- 如有报错，请提供完整报错文字和截图。
- 请说明 Windows 版本、Microsoft Office 版本，以及是否启用了 OCR。
