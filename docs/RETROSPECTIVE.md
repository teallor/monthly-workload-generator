# 项目复盘

原创作者：Rafael_Huang。本项目的需求定义、业务流程、测试验收、封版与发布由 Rafael_Huang 主导，CODEX 辅助代码实现和工程化整理。

## 做得好的地方

- 从固定月份演进为任意月份，preview 先行并按月份隔离。
- 培训和考核没有混写；照片课表得到 3 条培训、5 条考核及 24、8、8 汇总。
- GUI、CLI、服务和写入层共用业务逻辑。
- onefile EXE 内置 OCR，朋友无需 Python。
- 7 月最终 Excel 已由用户人工核对通过。

## 不足

- 根目录积累真实材料、多组输出、tmp、build、dist 和 workspace。
- 自动化测试建立较晚，目前仍以脚本化人工验收为主。
- CLI 未统一包装可预期异常，显示原始堆栈，且重定向中文可能乱码。
- README 曾保留已移除按钮的描述，文档同步检查不足。

## 当前发布判断

正式用户入口是中文GUI/EXE，CLI中文乱码只记为开发者体验问题。同名输出避让和OCR月份参数化通过定点回归，朋友端到端测试也已通过，因此v1.0允许正式结项。后续新需求进入v1.1。

## 下一轮原则

1. 先读结项文档，再改代码。
2. 先复现、后修改，一次解决一个问题。
3. 先补回归测试，再重新打包。
4. 真实材料不进入仓库或公开发布包。
5. 新功能另立版本，不直接修改 v1.0 封版目录。
