## 后续版本方向

- `v1.1.0`：OCR 增强，增加更多月份和版式 benchmark。
- `v1.2.0`：模板匹配增强，提高复杂表格和多模板适配。
- `v2.0.0`：规则配置与批量生成的大版本重构。

## 每次发布必须执行

1. 建立 `feature/功能名` 或 `fix/问题名` 分支。
2. 修改前保留当前可运行 EXE 和 SHA256。
3. 修改后执行 `docs/ACCEPTANCE_TEST.md`。
4. 验收通过后才合并 `main`。
5. 保留旧版，更新检查清单、发布历史和 GitHub Release。
6. OCR 改动必须回归非图片材料；OCR 失败不得阻断 Word、PDF、Excel。

历史标签不得删除或强制移动。补丁版本使用 `v1.0.1`，新增兼容功能使用 `v1.1.0`。
