# 用户使用手册

## 这个程序做什么

“月度工作量表自动生成器”读取课程通知、课表、PDF、Excel 和照片，先生成可核对的预览，再按工作量表模板生成指定月份 Excel。

## 使用前准备

1. 使用 Windows 电脑。
2. 建议安装 Microsoft Word 和 Excel，尤其是处理旧 `.doc/.xls` 时。
3. 把发布 ZIP 完整解压，不要直接在压缩包里运行。
4. 第一次先使用测试副本，不要直接处理唯一原件。

## 操作步骤

1. 双击 `月度工作量表自动生成器.exe`。
2. 点击“上传工作量表模板”，选择 `.xls` 或 `.xlsx` 模板。
3. 点击“上传课表/通知材料”，或“导入材料文件夹”。
4. 设置年份、月份、教师姓名和简称。
5. 点击“生成预览”。
6. 逐项检查待写入、排除课程、考核汇总和解析日志。
7. 有“需确认”时先核对或手工补录。
8. 点击“生成最终 Excel”，再次确认清单。
9. 点击“打开输出目录”查看结果。

图片上传后会自动 OCR，不需要寻找“启用 OCR”或“检测 OCR”按钮。识别失败时，普通 Word/PDF/Excel 仍可继续处理，可使用“手工补录课程”。

## 文件在哪里

程序会在自身旁边创建：

```text
workspace/
  templates/
  materials/YYYY-MM/
  sessions/YYYY-MM/
  output/YYYY-MM/
```

最终 Excel 位于 `workspace/output/YYYY-MM/`。已有同名文件时会生成 `_1`、`_2`，不会覆盖原文件。

## 常见问题

- **生成最终 Excel 是灰色**：必须先成功生成当前条件的预览。
- **照片识别不准**：换用清晰、平整、无反光、完整拍摄的图片，并核对 preview。
- **旧 Office 文件打不开**：安装 Microsoft Word/Excel，并关闭正在占用的文件。
- **Windows 提示未知发布者**：核对下载来源和 SHA256；不确定时请让电脑管理员检查。
- **程序没有反应**：onefile 首次启动需要解压，稍等后再操作。

任何自动识别结果都应先检查 preview，再生成正式 Excel。
